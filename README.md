# 小市值策略复现

忠实复现德邦证券 2022-04-20《金工小市值专题之一：小市值策略初探》，并在其上做样本外延长与变体。

**主结果：月频最小市值 100 只等权组合，2012-12-03 ~ 2022-03-31 年化 43.00%（研报 43.1%），一次跑出，未调参。**

| | 本文 | 研报 |
|---|---|---|
| 年化收益率 | **43.00%** | 43.1% |
| 最大回撤区间 | 2015-06-12 → 2015-07-08 | 同 |
| 调出组合总次数 | 2368 | 2401 |
| 成交口径 | **T+1 开盘** | T 日收盘（未来函数） |

⚠️ **两列不是同一个口径。** 研报用 T 日收盘价排名，再按**同一个已经知道的收盘价**成交——这是未来函数。本项目一度把它作为可选口径并行实现，为的是验证 43.1%；验证做完（月频两者只差 0.09pp）之后就把它删掉了，只留可执行的 T+1 开盘（[`grill.md`](grill.md) Q19）。所以本仓库跑出来的**不是研报那个数**，是「同样的策略，正确执行」的数。

## 描述

策略本身一句话说得完：对全 A 股按**总市值**升序取最小的 100 只等权持有、月度调仓，剔除 ST/\*ST、北交所、上市不满 20 个交易日的次新股，并在每个信号日额外剔除当日涨停与停牌的股票，成本按往返 0.3% 计，基准为中证 1000。

真正花功夫的是**怎么让这个数字可信**。研报有 31 张图、3 张表，头条那个 43.1% 是最容易蒙对也最容易蒙错的一个——四个自由参数（费率、调仓日、成交价、过滤条件）足够把任何数字凑出来。所以本项目的纪律写在 [`grill.md`](grill.md) 的 Q14：**所有假设在跑之前从论文原文先验固定，跑一次，如实报告跑出来的数；对不上时一次只动一个变量，记录「哪个假设、把结果推动了多少」。那张映射表比对上数字本身更有价值。**

据此做的事包括：

- **先用基准把口径钉死，再写策略。** 表1、表2 公布的中证 1000 行是纯指数序列，不掺组合构造，所以能精确对平。正是它揪出了两处一开始猜错的口径：年化收益按**自然日**折算而非 252 交易日（A 股一年只有约 243 个交易日，用 252 会把 9.7% 读成 10.10%、把 43.1% 抬到 45.0%）；分年度那一列的**收益**从上年末收盘起算，而**风险**只算年内（2016-01-04 熔断那天是判别性证据）。这些在 `tests/test_benchmark.py` 里固化成 31 个用例，含 9 组带日期的年度回撤。
- **无幸存者偏差。** 按区间取股票池并集而非块末名单——后者会漏掉块内退市的股票，方向上恰好高估收益。2013–2022 年间退市的 75 只股票全部在库，每只的数据恰好终止于其退市日。
- **先两种成交口径并行，验证完再删掉有偏的那条。** 实测月频下两者只差 **0.09pp**，这条结果证伪了项目早期「研报口径会显著放大收益」的判断；正因为月频下它无关紧要，删掉它不会动摇 43.1% 的复现结论。
- **结构性检查重于头条数字。** 市值分档 100→1000 的曲线在 800→900 处的非单调拐点与研报同处；调出次数 2368 对 2401；2018 年后名义双边换手率 38.0%（研报 30–40%）；最大回撤区间逐日吻合。

一句必须说清的话：**全时段对到 0.01pp 有运气成分，不要当成精度。** 分年度误差最大到 +4.2pp（2015）与 −3.0pp（2020），是正负相消之后才落在 43.1% 上的。支撑「复现成立」的是上面那些结构性证据，不是头条那个数字。

## 比头条数字更硬的证据：日历效应

研报 31 张图、3 张表全部复现之后，最能说明问题的不是 43.1%，是**图28 的日历效应**——它约束的是 2,267 个交易日的日收益按星期几的分组均值，也就是整条净值路径的细结构，而不是一个端点。四个自由参数可以凑出一个端点，凑不出这个：

| | 周一 | 周二 | 周三 | 周四 | 周五 |
|---|---|---|---|---|---|
| 2012.12-2016　本文 / 研报 | −0.05 / −0.07 | +0.10 / +0.11 | +0.15 / +0.15 | −0.22 / −0.21 | +0.01 / +0.03 |
| 2017-2018　　　本文 / 研报 | −0.10 / −0.11 | +0.32 / +0.32 | +0.03 / +0.04 | −0.15 / −0.14 | −0.09 / −0.10 |
| 2019-2022.3　　本文 / 研报 | +0.16 / +0.16 | +0.04 / +0.04 | +0.07 / +0.08 | −0.22 / −0.22 | −0.06 / −0.05 |

**15 个数，最大偏差 0.02pp。** 单位 %。值得一提的是这张表**对成交口径几乎免疫**——月频下换口径只挪动一个交易日的持仓，日收益路径的细结构不受影响。反过来说，它验证的是「持仓选得对」，不是「成交算得对」，两件事要分开看。

其余诊断同样逐条成立：图8/9 盈利股票基尼系数 0.446 > 亏损 0.336（收益由少数大涨股贡献，不是普涨）；图10 组合的横截面市值分位数月度变化 **97.3% 为正**而三大指数集中在 0 左侧；图12–14 三个阶段的卖出股价分位数**一致地**高出建仓 0.135–0.143（系统性低买高卖）；图15 行业分布前三 机械 19.2%、基础化工 11.1%、纺织服装 9.7%（研报 20%/11%/9%）；图27 与中证1000/500/300 的相关系数 0.938/0.903/0.678。

**两处对不齐的，照实写在 [`grill.md`](grill.md) 里**：图16 沪深300 的银行占比 21.5% vs 研报 12.77%（试过自由流通市值加权，只降到 17.2%，多半是研报用了指数自身的成分权重而非它注里写的总市值占比）；图24 换手率的水平比研报低一截（排序与形状都对，差在 `turnover_rate` 的流通股本口径）。

### 研报最反直觉的那个结论，是它自己的未来函数造出来的

研报 4.2 节说「日频调仓的策略相对而言显著跑输」，并解释为**调仓的滞后本身是收益来源**——组合继续持有那些已经涨出最小 100 名的股票。这一度是本项目认为最值得保留的反直觉结论。**换成可执行的成交口径之后，它不成立了：**

| 调仓频率 | T 日收盘成交（研报口径） | T+1 开盘成交（本文） |
|---|---|---|
| 月频 | 43.09% | 43.00%（−0.09pp） |
| 周频 | 45.70% | 49.12%（+3.42pp） |
| 日频 | **38.02%（最差）** | **51.89%（最好）** |

机制已查明。两种口径每天都恰好持有一个隔夜段和一个日内段，差别只在**是哪一个**：研报口径吃的是**选中后紧接着的那个隔夜**（T→T+1），本文吃的是再往后一天的（T+1→T+2）。实测 T 日选出的组合，其后第 k 个隔夜的等权平均收益：

| k | 1（研报口径吃的） | 2（本文吃的） | 3 | 5 | 10 |
|---|---|---|---|---|---|
| 均值 | **−0.1585%** | **−0.1226%** | −0.1189% | −0.1271% | −0.1432% |
| 2266 期连乘 | **0.0255** | **0.0577** | 0.0629 | 0.0523 | 0.0367 |

A 股整体的隔夜收益本来就是负的（同期全市场日均 −0.0951%），而**刚被选中的小市值股在次日早盘跌得尤其狠**，这个额外的负值一天之内就衰减掉大半。连乘差 2.26 倍，摊到 9.33 年约 +9.1% 年化，与观测到的 +13.9pp 同一量级。

**但也别信本文那个 51.89%。** 它同样不是小市值溢价，而是把一个隔夜/日内的微观结构效应捡了 2,267 次——真实的开盘集合竞价对微盘股吃不下这个量。真正的结论是第三条：**日频下「在收盘买还是次日开盘买」这一个选择就值 14pp，压过了频率本身的效应，所以研报关于调仓频率的结论不稳健，两个方向都不稳健。** 低频（月/周）下这个选择只值 0.09–3.4pp，那里的比较才可信。

### 一个研报没算对的地方，和一个它没数的东西

**图26 的「退市 0.08%」度量的不是它看起来度量的东西。** 本文口径下「因退市而被调出」恒为 **0**——组合持有过的股票里有 14 只后来真的退市了，但没有一只是在退市当天被调出的：它们平均提前 **496 天**就因停牌或戴帽被过滤链赶走了。研报那 2 次必然是按股票**后来的命运**归因。两种口径都成立，但「持有期间踩到退市股的概率」与「因退市而被动离场的频率」不是同一件事。

**而研报没数的那一类，恰恰是本文最该担心的**：按研报自己写明的选股范围如实分类，2368 次调出里有 **288 次（12.16%）是停牌**——每 8 次调出就有 1 次，引擎按冻结价"卖掉"了一只当天根本卖不掉的股票。这个方向上高估收益，是本项目已知的最大偏差源，待做成单变量敏感性项。

## 依赖

Python 3.11，环境见 `smallcap/` 的导入：

| 包 | 版本 | 用途 |
|---|---|---|
| pandas | 2.3.3 | 全部数据结构与向量化回测 |
| numpy | 1.26.4 | — |
| pyarrow | 25.0.0 | Parquet 读写 |
| pyyaml | 6.0.3 | 读 `config.yaml` |
| pytest | 9.1.1 | 测试 |
| matplotlib | 3.11.1 | 绘图（分析层）；**中文字体需显式设置**，实测选中 `PingFang SC` |
| scipy | 1.10.1 | 图10/12–14 的核密度估计 |
| rqdatac | 3.6.1 | **仅抓数时需要**，回测与测试全程离线 |

**关于数据**：`data/` 是 705 MB 的本地 Parquet 缓存，未进版本库。rqdatac 是有硬期限的试用授权，到期后 `scripts/01_fetch.py` 再也拉不出这份数据（含 2000 年起的后复权价与已退市股票的完整历史），所以它**需要在 git 之外单独备份**。没有 `data/` 时，依赖数据的测试会自动 skip，纯公式测试仍然可跑。

## 用法

```bash
# 回测与验收 —— 全程离线，不消耗 rqdatac 额度
python scripts/02_backtest.py           # 表1 对照 + 六项结构性检查，约 6 秒
python scripts/02_backtest.py --full    # 追加频率对比、市值分档、Q14 单变量敏感性

# 诊断图 —— 图6、8–28，写到 output/figures/
python scripts/03_analytics.py          # 图8–28，约 1 分钟
python scripts/03_analytics.py --deciles  # 追加图6 十分组（2007–2021）

# 测试 —— 174 个，1 秒跑完
python -m pytest tests/ -q

# 抓数 —— 仅在需要重建 data/ 时；先跑 --smoke
python scripts/01_fetch.py --smoke      # 校验接口并推算体量，只花几 MB
python scripts/01_fetch.py              # 真跑，可续传，已缓存的块自动跳过
```

全部可调参数集中在 [`config.yaml`](config.yaml)。
