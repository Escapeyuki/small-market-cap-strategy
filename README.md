# 小市值策略复现

忠实复现德邦证券 2022-04-20《金工小市值专题之一：小市值策略初探》。论文为基线，样本外延长与变体在其上叠加（进行中，见 [`PROJECT.md`](PROJECT.md)）。

**月频最小市值 100 只等权，2012-12-03 ~ 2022-03-31：年化 43.00%（研报 43.1%）——先验固定假设、一次跑出、未调参。**

> ⚠️ **两个口径，都标出来。** 研报全文 24 页从未交代它在什么价上成交（已逐页查证），所以「本项目」这一侧给两版，下文每张表都标清楚是哪版：
> - **旧版 · T 日收盘成交**：拿 T 日收盘价排名、再按同一收盘价成交——**未来函数**，已从引擎删除。它能把研报那个数复算到 **0.01pp**。
> - **新版 · T+1 开盘成交**：可执行口径，当前默认，对到 **0.1pp**。
>
> 每处「本项目 vs 研报」的差里都含一项**口径差**，不是纯复现误差。43.1% 本身反推不出口径——两版月频都四舍五入到 43.1%。理由见 [`grill.md`](grill.md) Q19。

## 策略本体（一句话）

全 A 股按**总市值**升序取最小 100 只、等权、月度调仓；剔除 ST/\*ST、北交所、上市不满 20 个交易日的次新股，信号日额外剔除当日涨停与停牌；成本往返 0.3%，基准中证 1000。全部参数见 [`config.yaml`](config.yaml)。

## 一个方向性发现：研报的频率结论翻转了

研报 4.2 节称「日频调仓显著跑输」，并把调仓滞后本身当成收益来源。换成可执行的 T+1 开盘成交后，结论翻转——日频从最差变最好：

| 调仓频率 | 旧版·T 日收盘 | 新版·T+1 开盘 |
|---|---:|---:|
| 月频 | 43.09% | 43.00% |
| 周频 | 45.70% | 49.12% |
| 日频 | **38.02%（最差）** | **51.89%（最好）** |

研报的日频结论只在**旧版（T 日收盘）**复现得出来——这是「研报用了 T 日收盘或等价的即时隔夜暴露」这一推断的唯一硬证据。机制：刚被选中的小市值股次日早盘跌得尤其狠（其后第 1 个隔夜均值 −0.159% vs 第 2 个 −0.123%），日频下把这个微观结构效应捡了 2,267 次。

**真正的结论：日频下「在收盘买还是次日开盘买」这一个选择就值 14pp，压过频率本身——所以研报的频率结论两个方向都不稳健，51.89% 同样不可信。** 低频（月/周）下这个选择只值 0.09–3.4pp，那里的比较才可信。机制详见 [`grill.md`](grill.md) Q19。

## 让这个数字可信

头条 43% 最容易蒙对也最容易蒙错，真正花功夫的是让它可信：

- **无幸存者偏差**：按区间取股票池并集（非块末名单），2013–2022 退市的 75 只股票全部在库，各自数据恰好终止于退市日。
- **口径先用基准钉死**：年化按**自然日**折算（非 252 交易日，否则 43.1% 会抬到 45.0%），分年度收益从上年末起算、风险只算年内——两条都由研报自己的中证 1000 基准行反解验证，固化成 `tests/test_benchmark.py`。
- **测试当护栏**：180 个测试 1 秒跑完，期望值全部可手算或对研报发布值。作用是「哪天对不上 43.1%，先排除公式/数据/引擎算错」。

## 已知偏差与口径澄清

| 项 | 说明 | 定性 |
|---|---|---|
| 停牌持仓「按冻结价卖出」 | 旧口径把当天停牌的持仓按冻结价调出（现实中卖不掉）；已加 `suspended` 开关可持有到复牌。实测**两面**——2015 **−33.3pp**、2014 **+8.0pp**，全时段仅 **−0.29pp**；研报头条也带此偏差（2015 +267%、回撤 54.7% 只有 baseline 对得上） | 已实现开关·作敏感性；**非"最大偏差源"**（频率高、幅度净小），baseline 仍作默认复现研报 |
| 图26 退市归因 = 0 | 三个口径数的不是一回事：调出当日状态（本文）**0**、曾持有后退市 **14（0.59%）**、研报 **2（0.08%）**。那 14 只濒退市股总先停牌/戴帽，平均提前 **496 天**被过滤、无一在退市日调出；研报的 2 夹在中间（更像"退市前后不久调出"或 Wind 多持有 2 只）。不挑窗口凑 2 | 口径不同，非偏差 |
| 图16 沪深300 银行占比 | 两个问题叠加：研报注写「总市值」实为**自由流通发布权重**，且分类须用 **citics_2019**（旧 `zx` 源把宁德时代错分到汽车）。两者一改，沪深300 全 28 行业对上研报（最大 0.62pp；发布权重按 citics_2019 汇总与研报逐行**一分不差**）。银行 21.5%→**12.3%**（研报 12.77）。连带修好图18 中证1000、推翻图15「说得太满」旧结论 | 已定位·已改（口径+分类源）|
| 图24 换手率水平 | 实测 `turnover_rate` 分母就是**流通A股**（比值 0.997）→ 旧口径偏低 2.55%；分母改用**自由流通市值**后升到 **3.66%**，逼近研报目测 4–6%。代价：跨组排序小变（中证1000 微反超小市值100） | 已定位·改口径 |

## 依赖

Python 3.11。

| 包 | 版本 | 用途 |
|---|---|---|
| pandas / numpy | 2.3.3 / 1.26.4 | 数据结构与向量化回测 |
| pyarrow | 25.0.0 | Parquet 读写 |
| pyyaml | 6.0.3 | 读 `config.yaml` |
| pytest | 9.1.1 | 测试 |
| matplotlib | 3.11.1 | 绘图；中文字体需显式设置（实测 `PingFang SC`） |
| scipy | 1.10.1 | 图10/12–14 核密度估计 |
| rqdatac | 3.6.1 | **仅抓数需要**；回测与测试全程离线 |

**数据不在版本库**：`data/` 是 713 MB 本地 Parquet 缓存（6,445 交易日 × 5,543 股，2000–2026），含 2000 年起的后复权价与已退市股完整历史。rqdatac 是有硬期限的试用授权，到期后 `01_fetch.py` 再也拉不出这份数据，**须在 git 之外单独备份**。缺 `data/` 时依赖数据的测试自动 skip，纯公式测试仍可跑。

## 用法

```bash
# 回测与验收 —— 全程离线，不消耗 rqdatac 额度
python scripts/02_backtest.py           # 表1 对照 + 六项结构性检查，约 6 秒
python scripts/02_backtest.py --full    # 追加频率对比、市值分档、Q14 单变量敏感性

# 诊断图 —— 图6、8–28，写到 output/figures/
python scripts/03_analytics.py          # 图8–28，约 1 分钟
python scripts/03_analytics.py --deciles  # 追加图6 十分组（2007–2021）

# 测试 —— 180 个，1 秒跑完
python -m pytest tests/ -q

# 抓数 —— 仅在需要重建 data/ 时；先跑 --smoke 校验接口
python scripts/01_fetch.py --smoke
python scripts/01_fetch.py              # 真跑，可续传，已缓存的块自动跳过
```
