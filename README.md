# 小市值策略复现

忠实复现德邦证券 2022-04-20《金工小市值专题之一：小市值策略初探》，并在其上做样本外延长与变体。

**主结果：月频最小市值 100 只等权组合，2012-12-03 ~ 2022-03-31 年化 43.09%（研报 43.1%），一次跑出，未调参。**

| | 本文 | 研报 |
|---|---|---|
| 年化收益率 | **43.09%** | 43.1% |
| 年化波动率 | 32.4% | 32.1% |
| 夏普比率 (rf=2%) | 1.269 | 1.28 |
| 最大回撤 | 55.6% | 54.7% |
| 最大回撤区间 | 2015-06-12 → 2015-07-08 | 同 |
| 调出组合总次数 | 2368 | 2401 |

## 描述

策略本身一句话说得完：对全 A 股按**总市值**升序取最小的 100 只等权持有、月度调仓，剔除 ST/\*ST、北交所、上市不满 20 个交易日的次新股，并在每个调仓日额外剔除当日涨停与停牌的股票，成本按往返 0.3% 计，基准为中证 1000。

真正花功夫的是**怎么让这个数字可信**。研报有 31 张图、3 张表，头条那个 43.1% 是最容易蒙对也最容易蒙错的一个——四个自由参数（费率、调仓日、成交价、过滤条件）足够把任何数字凑出来。所以本项目的纪律写在 [`grill.md`](grill.md) 的 Q14：**所有假设在跑之前从论文原文先验固定，跑一次，如实报告跑出来的数；对不上时一次只动一个变量，记录「哪个假设、把结果推动了多少」。那张映射表比对上数字本身更有价值。**

据此做的事包括：

- **先用基准把口径钉死，再写策略。** 表1、表2 公布的中证 1000 行是纯指数序列，不掺组合构造，所以能精确对平。正是它揪出了两处一开始猜错的口径：年化收益按**自然日**折算而非 252 交易日（A 股一年只有约 243 个交易日，用 252 会把 9.7% 读成 10.10%、把 43.1% 抬到 45.0%）；分年度那一列的**收益**从上年末收盘起算，而**风险**只算年内（2016-01-04 熔断那天是判别性证据）。这些在 `tests/test_benchmark.py` 里固化成 31 个用例，含 9 组带日期的年度回撤。
- **无幸存者偏差。** 按区间取股票池并集而非块末名单——后者会漏掉块内退市的股票，方向上恰好高估收益。2013–2022 年间退市的 75 只股票全部在库，每只的数据恰好终止于其退市日。
- **两种成交口径并行。** `report_close`（研报口径，T 日收盘排名 + T 日收盘成交，属轻度未来函数）与 `next_open`（T+1 开盘成交，可实盘执行）。实测月频下只差 **0.09pp**——这条结果**证伪了**项目早期「研报口径会显著放大收益」的判断。
- **结构性检查重于头条数字。** 市值分档 100→1000 的曲线在 800→900 处的非单调拐点与研报同处；调出次数 2368 对 2401；频率对比复现了研报最反直觉的结论（月 43.1 / 周 45.7 / 日 38.0——调仓的滞后本身是收益来源）。

一句必须说清的话：**全时段对到 0.01pp 有运气成分，不要当成精度。** 分年度误差最大到 +4.2pp（2015）与 −3.0pp（2020），是正负相消之后才落在 43.1% 上的。支撑「复现成立」的是上面那些结构性证据，不是头条那个数字。

## 依赖

Python 3.11，环境见 `smallcap/` 的导入：

| 包 | 版本 | 用途 |
|---|---|---|
| pandas | 2.3.3 | 全部数据结构与向量化回测 |
| numpy | 1.26.4 | — |
| pyarrow | 25.0.0 | Parquet 读写 |
| pyyaml | 6.0.3 | 读 `config.yaml` |
| pytest | 9.1.1 | 测试 |
| matplotlib | 3.11.1 | 绘图（分析层，尚未启用） |
| rqdatac | 3.6.1 | **仅抓数时需要**，回测与测试全程离线 |

**关于数据**：`data/` 是 705 MB 的本地 Parquet 缓存，未进版本库。rqdatac 是有硬期限的试用授权，到期后 `scripts/01_fetch.py` 再也拉不出这份数据（含 2000 年起的后复权价与已退市股票的完整历史），所以它**需要在 git 之外单独备份**。没有 `data/` 时，依赖数据的测试会自动 skip，纯公式测试仍然可跑。

## 用法

```bash
# 回测与验收 —— 全程离线，不消耗 rqdatac 额度
python scripts/02_backtest.py           # 表1 对照 + 六项结构性检查，约 6 秒
python scripts/02_backtest.py --full    # 追加频率对比、市值分档、Q14 单变量敏感性

# 测试 —— 132 个，1 秒跑完
python -m pytest tests/ -q

# 抓数 —— 仅在需要重建 data/ 时；先跑 --smoke
python scripts/01_fetch.py --smoke      # 校验接口并推算体量，只花几 MB
python scripts/01_fetch.py              # 真跑，可续传，已缓存的块自动跳过
```

全部可调参数集中在 [`config.yaml`](config.yaml)。
